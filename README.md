- 外部フォントが読み込めない場合は端末の明朝体などへフォールバック。通常BGMは既存の16音ループから、短調の4小節（ドラム・ベース・コードスタブ・主旋律）へ変更し、最終戦ではテンポを上げて演奏。BGMの作曲・音色は試作段階で、今後も耳で確認して調整する

フォント著作権・ライセンス： [Yuji / Kinuta Font Factory](https://github.com/Kinutafontfactory/Yuji)（SIL OFL 1.1）

## ルール

- 玉を落として同種の玉同士を合体させ、得点を稼ぐ
- 危険ラインを越えた状態が6.6秒継続すると「そこまで！」。超過中は画面全体が赤く明滅し、赤い進行バーと残り秒数を表示。超過が解消すれば警告と計時はリセット
- **投げゲージ**：従来の高さ方式で、獲得量を従来比2倍に調整。落とした玉（途中で合体した場合は合体後の玉）の高さ・速度を追跡し、高さがほぼ落ち着いた時に加算する。**次の玉の投下解禁とは独立**して判定する。床に近いほどほぼゼロ、上方に設置されるほど二乗で増える。大きな球ほど増分が大きく、追跡中の球同士が合体したら二重加算しない。
- **打撃ゲージ**：効果・技あり・一本の成立待ち玉を叩くことで獲得。当初比1/8に調整し、初打は0.3125%、同じ玉の次打までが110ms以下なら0.625%、170ms以下0.53125%、260ms以下0.40625%、400ms以下0.28125%、それ以降0.15625%。ミスしたタップや黒玉・通常玉への打撃では増えない。連打によるゲージ増加は成立の成功／失敗に関係なく、有効打撃ごとに獲得。
- **両ゲージは独立**。それぞれ0〜100%。30%で発動可能。溜まっている全量を使い、持続時間は『3秒＋(ゲージ% − 30) × 0.1秒』（30%なら3.0秒、50%なら5.0秒、75%なら7.5秒、100%なら10.0秒）。残り3秒のカウントダウンを最後まで見られるよう、3秒未満のラッシュは発動しない。片方を使っても他方は減らない。
- **ラッシュ使用可能の大型宣告**：打撃または投げゲージが30%を初めて超えた瞬間に、技あり等と同じ中央宣告HUDで「打撃ラッシュOK！」「投げラッシュOK！」を表示する。ラッシュOKの2種類だけ文字をやや小さくし、アニメーションの拡大中も実際のフィールド幅に収める（回転・リサイズ時も再計算）。「技あり！」など他の宣告は従来サイズのまま。成立技の宣告中なら終了を待って順番に表示。30%を超えている間は繰り返さず、ゲージを消費して再び30%に達したら再表示する。
- **打撃ラッシュ**：物理演算を止めて叩く。100%発動時だけ1打の破壊ダメージを1.25倍（通常は1）にする。対象が成立待ちの特殊玉であれば通常どおり1打としてカウントし、特殊玉の成立に必要な打数は変えない。
- **投げラッシュ**：玉を自由に掴んで移動させる。100%発動時だけ、開始時に盤面の黒玉（注意・警告・失格）をすべて消去する。黒玉消去で得点や新たな合体は発生させない。
- **破壊耐久値はラッシュごとにリセット**：黒玉と通常玉が打撃ラッシュ中に受けた破壊ダメージは、ラッシュ終了時に破棄し、次回は満タンから。技の成立待ち玉を叩いた進捗は別扱いで、ラッシュ終了時にもリセットしない。
- **打撃ラッシュ（30〜100%の全量消費）**：最大10秒、物理演算を停止。**黒玉（注意・警告・失格）は基本4・8・16ダメージで破壊**。通常の玉も進化レベル n に対し `2^n` ダメージで破壊。100%発動なら1打1.25ダメージとなり、必要な実打数が減る場合がある。ラッシュ終了後は物理処理を再開する。
- **投げラッシュ（30〜100%の全量消費）**：最大10秒間、通常の物理処理を継続しつつ玉の合体判定だけを停止。玉をドラッグして動かし、何度でも掴み直せる。成立待ち玉をタップした場合は連打を優先。掴んだまま時間切れになった場合も強制的にリリースし、物理・合体処理に戻る。100%発動では黒玉を開幕全消去。
- **ラッシュ残り3秒からの大型カウントダウン**：打撃・投げのどちらも、盤面中央に小さく「ラッシュ残り」、大きく3・2・1を表示する。背景が透ける文字表示のみで、打撃やドラッグの操作判定には影響しない。技が成立して落下が700msだけ無効になる間も、ラッシュの残り時間と数字は通常どおり進む
- **ラッシュ終了の一時停止演出**：打撃・投げとも時間切れ直後、盤面中央に大きく「終了！」とラッシュ種別を約1.1秒表示。表示中はゲーム全体を硬直させ、玉の移動・物理・合体・操作・ほかの成立待ち玉の9秒タイマー・危険ライン・ゲージ確定・ラッシュ破壊耐久・粒子更新を完全に止める。終了表示専用時計で1.1秒経過した後、凍結時の状態から再開。投げラッシュで掴んでいた玉はラッシュ終了時に通常どおり解放する。
- スコアに応じて架空のゲーム内段位認定。ハイスコアはブラウザ内に保存

## 特殊技の連打成立と黒玉

**合体によって効果・技あり・一本が生まれた瞬間に9秒の成立待ち**になる。落下操作そのものに制限時間はない。

| 合体後の玉 | 成立まで | 9秒以内に不成立の場合 | 打撃ラッシュでの黒玉破壊 |
| --- | ---: | --- | ---: |
| 効果 | 4発 | 注意（黒玉、半径30px） | 4発 |
| 技あり | 8発 | 警告（黒玉、半径51px） | 8発 |
| 一本 | 16発 | 失格（黒玉、半径79px） | 16発 |

- 成立待ちの玉の文字は小さめに表示し、玉の中央下に残り打撃回数、上に9からの秒単位カウントダウン、外周に9秒の残量リングを表示する。**残り時間が9秒の35%未満（約3.15秒）になるとリングと同時に玉全体も赤く明滅**し、文字・残り回数は明滅の上に描いて視認性を維持する。玉の外側に**高速拡縮する拳アイコン**も表示し、タップ操作を促す
- 成立待ち中は同種の玉と接触しても合体しない。連打が完了すると通常の玉に確定し、該当する合体点が加算され、技名を宣告する。すでに同種の玉に接していた場合は合体判定を再取得する
- **成立待ち玉のタップ判定は見た目の外周から12px拡張**する（当たり判定の拡大は打撃入力限定。物理・衝突判定は従来どおり）。複数候補があるときはタップ位置に近いものを選ぶ
- 制限時間切れの黒玉は元の大きさ・物理演算のまま残り、他の玉（黒玉同士も含む）と合体しない。**通常時は何回叩いても消せない**。黒玉は打撃ラッシュ中に破壊できるほか、投げラッシュを満タン発動すると全消去。打撃による黒玉の耐久減少はラッシュをまたいで引き継がない。
- 効果の玉がランダムの次玉として直接供給された場合は成立済みの通常玉であり、連打対象ではない。特殊な成立待ちは「合体で新しく生まれた玉」にのみ付く
- 成立待ちが複数あってもそれぞれ独立した9秒タイマーで管理し、打撃／投げラッシュ中もカウントダウンは継続する

## 盤面全体のタップ操作（打撃を優先）

**通常時はゲーム盤面のどこでもタップして離すと玉を落とせます。** 空いている場所でも、成立待ちでない玉の上でも、タップしたX位置へ落下します。空いている場所を押しながら左右に動かすと落下位置プレビューが追従し、離したときに落下します。スマホで特別な操作帯・長押しは不要。PCではキャンバスにフォーカスして左右キー＋Enter／Spaceでも投下できます。

**効果・技あり・一本の成立待ち玉の上だけ、落下より打撃を優先します。** 玉の輪郭より12px大きいタップ判定を使用し、叩いた指を離しても玉は落下しません。別の指を使った連打にも対応。成立待ち玉以外へのタップでは通常の落下になり、黒玉は打撃ラッシュ中のみ破壊できます。打撃ラッシュ中はどの玉もタップで叩き、投げラッシュ中は玉をドラッグします。

### 投げゲージの設置完了と投下のルール

- **次玉は前回の投下から500ms経過した時点で再び落とせる**。静止・着地の判定は次玉解禁には使用しない。ゲージ加算だけは従来の速度180ms／高さ±2.5px以内220msの静止条件を維持し、3.2秒後のフォールバックも維持する。
- 投げゲージ加算式（調整用）：\`h = clamp((床Y - (設置玉の中心Y + 半径))/(床Y - 危険ラインY), 0, 1)\`、\`ゲージ加算 = 1.5 × 1.4 × h² × (3 + 1.1 × 段階)\`。突を段階0とする。床への直接設置では基本0
- 合体後も設置対象の追跡を引き継ぎ、最終段階同士の合体で消えた場合は加算なし。ラッシュ中は設置判定を進めない

- **「蹴」＋「蹴」→「効果」** は連打成立後に「効果！」と表示・発声する（技あり・一本も同様）。スマホは現行のCC0実録掛け声素材（日本語セリフではない）を鳴らす

## ボイスの暫定対応

- PC: 端末の Web Speech API（日本語読み上げ）を優先
- スマートフォン: Web Speech APIが無音になる環境があるため、CC0の実録男性掛け声・叫び声をWeb Audio APIで再生する暫定方式。iPhone/iPadもAndroidと同じ録音データを使用。iPadOSのデスクトップ相当UAも判定する。
- **iPhone/iPadの音声再生対策（2026-10-23）**: Safari対応環境ではAudioContext作成前に`navigator.audioSession.type='playback'`を設定してサイレントスイッチ中のWeb Audio無音を回避。タッチ終了・クリックのユーザー操作中に無音Web Audioバッファを再生して音声をアンロックする。Safariがバックグラウンド移行等でAudioContextを`interrupted`状態にした際も再開を試み、画面復帰と次のタップで再試行する。この時点では効果音・BGMの音色・音量・ルールを変更せず、後続の2026-10-23更新で格闘ゲーム風サウンド試作を導入。
- **実機確認**: iPhone Safariで通常モードの開始音・BGM・落下/打撃SE・掛け声、音量/声のON/OFF、別アプリから戻った後の再生を確認する。iOSのバージョンや機種による制約があるため、全機種で音が出ることを保証するものではない。
- スマホ用音声は現在、別の公開GitHubリポジトリ内の素材を読み込むため、ネット接続が必要です。録音は**日本語のセリフそのものではなく、短い掛け声・うめき・長い叫び声**です。実際の「セイッ」「そこまで！」音声への差し替えは今後の課題です。取得に失敗した場合、画面の声ボタンに「声 読込失敗」と表示します
