# 大道塾 - DDJ GAME

空道をモチーフにした非公式・一人用・無料のブラウザ向け落ち物パズルです。実在団体の公式作品ではありません。通常のゲームプレイに時間制限はありません。

## 進化順序とサイズ

| 順序 | 文字 | 半径(px) |
| ---: | :--- | ---: |
| 1 | 突 | 16 |
| 2 | 蹴 | 22 |
| 3 | 効果 | 30 |
| 4 | 投 | 40 |
| 5 | 技あり | 51 |
| 6 | 極 | 64 |
| 7 | 一本 | 79 |
| 8 | 空道 | 97 |
| 9 | 大道塾 | 116 |

通常玉は同じ文字同士が接触すると次の段階へ合体します。塾長ボールは廃止し、空道は旧・塾長ボールの半径97px、最終大道塾は暫定116pxにしました。ゲーム画面は360×525の固定論理座標（初期360×480と一度拡張した360×570の中間）に調整し、CSSでも同じ縦横比を維持します。最終段階の「大道塾」同士が合体した場合は消滅し、得点が入ります。球の摩擦・静止摩擦・空気抵抗は大きめに調整しています。漢字もボール本体の回転角度に連動して回ります。

## 滝背景・盤面拡張（2026-10-21）

- 生成した夕焼けの滝と岩山を軽量WebP（200×316px、約6.6KB）としてゲーム本体に同梱し、360×525論理画面へ描画。玉の視認性のため半透明の暗色レイヤーを敷く
- 床Y=515、危険ラインY=96。初期の床Y=470／危険ラインY=103と一度拡張した床Y=560／危険ラインY=88の中間にして、難易度を調整
- 危険ライン超過の猶予時間は2.2秒から6.6秒へ変更、残り秒数と赤い点滅で警告する
- 落下の操作感は500msの時間式に戻し、ゲージの高さ停止判定は別に管理する

## 技成立後の誤落下防止（2026-10-21）

- 効果・技あり・一本が成立すると**700msのゲーム全体硬直**が発生する。『効果！』『技あり！』『一本！』などの宣告HUDだけは表示・演出を続ける
- **玉の移動／物理演算／合体／追加打撃／落下／打撃・投げラッシュの残り時間／危険ライン超過の猶予／他の成立待ち玉の9秒カウントダウン／ラッシュゲージの確定判定／エフェクト更新**をすべて停止する。硬直が終われば凍結時の残り時間・位置から再開する
- タッチを連打しても硬直中は新しい落下・打撃を受け付けず、硬直前から押されている落下・投げドラッグ入力は解放して持ち越さない。普段の次玉投下は従来どおり500ms時間方式

## 画面デザイン（2026-10-21）

- 90年代前半のアーケード格闘ゲームを思わせる、赤・黒・金の金属フレーム風UIを採用。特定作品のロゴ・画像・音素材は使用していない
- タイトル画面は「**大道塾藝夢**」の一行ベクター筆文字ロゴ。筆文字フォントに多層の縁取り、立体影、固定のかすれ線と放射線を重ね、スマートフォンでも横幅に追従する
- タイトルの赤黒い背景、スコア表示、ラッシュゲージ、ボタン、技宣告、結果表示も統一。狭い端末ではタイトル／リザルトパネル内だけスクロールして操作ボタンへアクセスできる
- **玉の色、合体・打撃の入力ロジック、成立待ち9秒は維持**。ロゴはインラインSVGで、ゲーム背景は滝と夕焼けの岩山画像へ変更。

## 演出・効果音（2026-10-20 更新）

- 合体時の音を再調整。**約24msの鋭い高域破裂音＋約75msの中域打撃音＋低音の胴鳴り**を重ね、立ち上がり約1〜2msで「バシッ！」寄りに強化。ボールが大きいほど胴鳴り・二段打ちを追加
- 合体・打撃時には白い芯・長さの不揃いな鋭い棘・薄い灰色の縁をもつ格闘ゲーム風スパークを描画。大きな合体は画面揺れを追加。背景には夕焼けの岩山と滝の画像を表示
- 打撃ラッシュ時も小型スパーク、破壊時は強めの打撃音とヒットスパーク
- タイトル・開始・終了・段位認定に加え、**落下中・盤面上のボール文字・次ボール予告もYuji Bokuの筆書体に統一**。スコアやボタンの一部は従来の読みやすいフォントを維持
- 打撃SE、ヒットスパークの画像はWeb Audio APIとCanvasで生成しており、音素材・画像素材の追加も追加料金も不要
- 外部フォントが読み込めない場合は端末の明朝体などへフォールバック。音声・BGMに対する既存仕様の変更はなし

フォント著作権・ライセンス： [Yuji / Kinuta Font Factory](https://github.com/Kinutafontfactory/Yuji)（SIL OFL 1.1）

## ルール

- 玉を落として同種の玉同士を合体させ、得点を稼ぐ
- 危険ラインを越えた状態が6.6秒継続すると「そこまで！」。超過中は画面全体が赤く明滅し、赤い進行バーと残り秒数を表示。超過が解消すれば警告と計時はリセット
- **ラッシュゲージは玉を落とした時・合体した時には増えない。** 落とした玉（途中で合体した場合は合体後の玉）の高さ・速度を追跡し、高さがほぼ落ち着いた時に加算する。**次の玉の投下解禁とは独立**して判定する。床に近いほどほぼゼロ、上方に設置されるほど二乗で増える。大きな球ほど増分が大きく、追跡中の球同士が合体したら二重加算しない。
- **打撃ラッシュ（50%消費）**：6秒間すべての玉の物理演算を停止。**黒玉（注意・警告・失格）は4・8・16発で破壊**。通常の玉も従来どおり進化レベル n に対し `2^n` 発で破壊可能。ラッシュ終了後は物理処理を再開する
- **投げラッシュ（100%消費）**：3秒間、通常の物理処理を継続しつつ玉の合体判定だけを停止。玉をドラッグして動かし、何度でも掴み直せる。成立待ち玉をタップした場合は連打を優先。掴んだまま時間切れになった場合も強制的にリリースし、物理・合体処理に戻る
- スコアに応じて架空のゲーム内段位認定。ハイスコアはブラウザ内に保存

## 特殊技の連打成立と黒玉

**合体によって効果・技あり・一本が生まれた瞬間に9秒の成立待ち**になる。落下操作そのものに制限時間はない。

| 合体後の玉 | 成立まで | 9秒以内に不成立の場合 | 打撃ラッシュでの黒玉破壊 |
| --- | ---: | --- | ---: |
| 効果 | 4発 | 注意（黒玉、半径30px） | 4発 |
| 技あり | 8発 | 警告（黒玉、半径51px） | 8発 |
| 一本 | 16発 | 失格（黒玉、半径79px） | 16発 |

- 成立待ちの玉の文字は小さめに表示し、玉の中央下に残り打撃回数、上に9からの秒単位カウントダウン、外周に9秒の残量リングを表示する。玉の外側に**高速拡縮する拳アイコン**も表示し、タップ操作を促す
- 成立待ち中は同種の玉と接触しても合体しない。連打が完了すると通常の玉に確定し、該当する合体点が加算され、技名を宣告する。すでに同種の玉に接していた場合は合体判定を再取得する
- **成立待ち玉のタップ判定は見た目の外周から12px拡張**する（当たり判定の拡大は打撃入力限定。物理・衝突判定は従来どおり）。複数候補があるときはタップ位置に近いものを選ぶ
- 制限時間切れの黒玉は元の大きさ・物理演算のまま残り、他の玉（黒玉同士も含む）と合体しない。**通常時は何回叩いても消せない**。黒玉は打撃ラッシュ中にだけ破壊でき、回数はラッシュをまたいで引き継ぐ
- 効果の玉がランダムの次玉として直接供給された場合は成立済みの通常玉であり、連打対象ではない。特殊な成立待ちは「合体で新しく生まれた玉」にのみ付く
- 成立待ちが複数あってもそれぞれ独立した9秒タイマーで管理し、打撃／投げラッシュ中もカウントダウンは継続する

## 盤面全体のタップ操作（打撃を優先）

**通常時はゲーム盤面のどこでもタップして離すと玉を落とせます。** 空いている場所でも、成立待ちでない玉の上でも、タップしたX位置へ落下します。空いている場所を押しながら左右に動かすと落下位置プレビューが追従し、離したときに落下します。スマホで特別な操作帯・長押しは不要。PCではキャンバスにフォーカスして左右キー＋Enter／Spaceでも投下できます。

**効果・技あり・一本の成立待ち玉の上だけ、落下より打撃を優先します。** 玉の輪郭より12px大きいタップ判定を使用し、叩いた指を離しても玉は落下しません。別の指を使った連打にも対応。成立待ち玉以外へのタップでは通常の落下になり、黒玉は打撃ラッシュ中のみ破壊できます。打撃ラッシュ中はどの玉もタップで叩き、投げラッシュ中は玉をドラッグします。

### 設置完了と投下のルール

- **次玉は前回の投下から500ms経過した時点で再び落とせる**。静止・着地の判定は次玉解禁には使用しない。ゲージ加算だけは従来の速度180ms／高さ±2.5px以内220msの静止条件を維持し、3.2秒後のフォールバックも維持する。
- 加算式（調整用）：\`h = clamp((床Y - (設置玉の中心Y + 半径))/(床Y - 危険ラインY), 0, 1)\`、\`ゲージ加算 = 1.4 × h² × (3 + 1.1 × 段階)\`。突を段階0とする。床への直接設置では基本0
- 合体後も設置対象の追跡を引き継ぎ、最終段階同士の合体で消えた場合は加算なし。ラッシュ中は設置判定を進めない

- **「蹴」＋「蹴」→「効果」** は連打成立後に「効果！」と表示・発声する（技あり・一本も同様）。スマホは現行のCC0実録掛け声素材（日本語セリフではない）を鳴らす

## PCで実行

`index.html` をChrome / Edgeで開いてプレイできます。スマホではGitHub Pagesから起動します。物理演算ライブラリ Matter.js v0.20.0 は `vendor/` に同梱してあります。

## ボイスの暫定対応

- PC: 端末の Web Speech API（日本語読み上げ）を優先
- スマートフォン: Web Speech APIが無音になる環境があるため、CC0の実録男性掛け声・叫び声をWeb Audio APIで再生する暫定方式
- スマホ用音声は現在、別の公開GitHubリポジトリ内の素材を読み込むため、ネット接続が必要です。録音は**日本語のセリフそのものではなく、短い掛け声・うめき・長い叫び声**です。実際の「セイッ」「そこまで！」音声への差し替えは今後の課題です。取得に失敗した場合、画面の声ボタンに「声 読込失敗」と表示します

### 音声素材の出典・利用条件

音声の録音元：HaelDB **Male Grunt/Yelling sounds**（CC0 1.0）、 https://opengameart.org/content/male-gruntyelling-sounds

暫定的に読み込むファイルは、オリジナルの録音から加工された `player-pain-1.wav`、`player-pain-2.wav`、`player-death.wav` です。参照元： https://github.com/transitive-bullshit/ai-safety-doom/tree/main/public/game/audio

これらはゲーム本体の正式な日本語声素材ではありません。実録CC0音源のみを採用し、他作品の著作物のゲーム音源は利用していません。
