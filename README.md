# 大道塾 - DDJ GAME

空道をモチーフにした非公式・一人用・無料のブラウザ向け落ち物パズルです。実在団体の公式作品ではありません。通常のゲームプレイに時間制限はありません。

## 進化順序とサイズ

| 順序 | 文字 | 半径(px) |
| ---: | :--- | ---: |
| 1 | 突 | 16 |
| 2 | 蹴 | 22 |
| 3 | 効果 | 30 |
| 4 | 投 | 40 |
| 5 | 技あり | 51 |
| 6 | 極 | 64 |
| 7 | 一本 | 79 |
| 8 | 塾長 | 97 |
| 9 | 空道 | 116 |
| 10 | 大道塾 | 134 |

同じ文字同士が接触すると次の段階へ合体します。最終段階の「大道塾」同士が合体した場合は消滅し、得点が入ります。球の摩擦・静止摩擦・空気抵抗は大きめに調整しています。漢字もボール本体の回転角度に連動して回ります。

## ルール

- 玉を落として同種の玉同士を合体させ、得点を稼ぐ
- 危険ラインを一定時間越えると「そこまで！」
- ゲージ増加は以前の約5分の1。落下玉が大きいほど増えやすく、積み上がるほど危険度ボーナスが加わる
- **打撃ラッシュ（50%消費）**：6秒間、すべての玉の物理演算を停止。タップで玉を叩いて破壊する。必要打撃回数は進化レベル n （「突」が n=0）に対して `2^n` 回（1、2、4、8、16、32、64、128、256、512回）。終了後に物理処理を再開する
- **投げラッシュ（100%消費）**：3秒間、通常の物理処理を継続しつつ玉の合体判定だけを停止。玉をドラッグして動かし、何度でも掴み直せる。掴んだまま時間切れになった場合も強制的にリリースし、物理・合体処理に戻る
- スコアに応じて架空のゲーム内段位認定。ハイスコアはブラウザ内に保存

## PCで実行

`index.html` をChrome / Edgeで開いてプレイできます。スマホではGitHub Pagesから起動します。物理演算ライブラリ Matter.js v0.20.0 は `vendor/` に同梱してあります。

## ボイスの暫定対応

- PC: 端末の Web Speech API（日本語読み上げ）を優先
- スマートフォン: Web Speech APIが無音になる環境があるため、CC0の実録男性掛け声・叫び声をWeb Audio APIで再生する暫定方式
- スマホ用音声は現在、別の公開GitHubリポジトリ内の素材を読み込むため、ネット接続が必要です。録音は**日本語のセリフそのものではなく、短い掛け声・うめき・長い叫び声**です。実際の「セイッ」「そこまで！」音声への差し替えは今後の課題です。取得に失敗した場合、画面の声ボタンに「声 読込失敗」と表示します

### 音声素材の出典・利用条件

音声の録音元：HaelDB **Male Grunt/Yelling sounds**（CC0 1.0）、 https://opengameart.org/content/male-gruntyelling-sounds

暫定的に読み込むファイルは、オリジナルの録音から加工された `player-pain-1.wav`、`player-pain-2.wav`、`player-death.wav` です。参照元： https://github.com/transitive-bullshit/ai-safety-doom/tree/main/public/game/audio

これらはゲーム本体の正式な日本語声素材ではありません。実録CC0音源のみを採用し、他作品の著作物のゲーム音源は利用していません。
